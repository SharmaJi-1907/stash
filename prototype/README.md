# Prototype

`stash-prototype.html` is an early standalone visual skeleton, written before the
specification in `docs/` was settled. It is kept for reference only.

- Not part of the build. No workspace, no dependencies, nothing imports it.
- Not authoritative on anything. Where it disagrees with
  [`../docs/04-DESIGN-SYSTEM.md`](../docs/04-DESIGN-SYSTEM.md), the design system wins.

Open it directly in a browser if you want to look at it.
