Stash

This page exists to answer one question: does Android put Stash in the share sheet, and does what you share arrive intact?

Checking…

What to do

  1. Open this page in Chrome on the phone.
  2. Menu (⋮) → Add to Home screen / Install app.
  3. Open YouTube, pick any video, tap Share.
  4. Look for Stash in the sheet. Tap it.

If Stash is not in the sheet

Uninstall the app completely and install it again. Android caches the manifest, and a reinstall is the only thing that picks up a change to it.
